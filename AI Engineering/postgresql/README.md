# Postgresql

A powerful open-source relational database management system (RDBMS) used to store, organize, manage, and retrieve data efficiently.

## Key Features

- **Open Source** – Free to use and backed by a large community.
- **SQL Compliant** – Supports standard SQL and many advanced features.
- **Reliable and Stable** – Widely used in production systems.
- **ACID Transactions** – Ensures data consistency and integrity.
- **Advanced Data Types** – Supports JSON, arrays, UUIDs, geometric types, and more.
- **Scalable** – Handles small projects as well as large enterprise applications.
- **Extensible** – You can create custom functions, operators, and data types.
- **Vector Database** – pgvector.
